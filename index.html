Whole-body Mobile Manipulation

Abstract

Mobile manipulation requires generating whole-body action chunks that jointly satisfy goal reaching, collision avoidance, base kinematic constraints, manipulator joint limits, trajectory smoothness, and base-arm coordination. RLMM-Flow first pretrains a point-cloud-conditioned transformer flow policy on expert whole-body trajectories. The pretrained flow policy is then frozen, while a latent actor steers its initial noise toward higher-value action chunks. To stabilize high-dimensional latent optimization, RLMM-Flow warms up an action-space critic before latent actor-critic optimization and progressively expands latent control from a low-dimensional horizon-shared representation to a high-dimensional residual representation.

Method overview

RLMM-Flow Pipeline

RLMM-Flow separates trajectory-prior learning from reward-guided policy improvement. Expert pretraining provides a stable multimodal whole-body motion prior; offline RL then improves the initial flow noise without modifying the pretrained generator.

Given a robot-centric local 3D point cloud, the current robot state, and the task goal, the model directly predicts a future action chunk for both the mobile base and manipulator. In the first stage, high-quality expert trajectories are used to pretrain the flow policy. In the second stage, an action critic learns trajectory value from offline transitions, a latent critic distills action-space value into the flow latent space, and a latent actor learns to produce higher-value initial noise. Because the flow policy remains frozen, reward optimization preserves the learned motion prior and adds only negligible inference overhead.

Architecture

Network Architecture

RLMM-Flow contains four main networks: a pretrained flow policy, a latent actor πW, an action critic QA, and a latent critic QW.

The latent steering network adopts a cascaded Transformer architecture. Since the mobile base and manipulator have different motion roles, the network first predicts the base-related latent component and then predicts the arm-related latent component conditioned on the base prediction. This structured latent steering captures the dependency between global navigation and local manipulation.

Core contributions

Key Innovations

QA
Warm‑up

Action-Critic Warm-up Stabilizes Latent Value Learning

The latent critic QW is supervised by values produced by the action critic QA. Jointly training both critics from the beginning creates a moving-target problem: QW must fit action-space values that are still inaccurate and rapidly changing. RLMM-Flow therefore trains QA alone during the first 20k update steps, then starts latent-critic distillation and latent-actor optimization.

Warm-up is not merely extra training time. It improves the supervision quality available to QW, reduces late-stage latent-critic loss, and provides a more reliable optimization direction for the latent actor. In the experiments, the QA variant primarily improves joint constraints, smoothness, and manipulator joint-path length.

Coarse
→ Fine

Coarse-to-Fine Latent Steering Reduces High-Dimensional Search Difficulty

The latent actor first outputs a full-dimensional raw latent. The coarse branch averages this latent over the action-horizon dimension and repeats the pooled representation across the horizon. This horizon-shared latent preserves global steering information—such as the base motion direction, obstacle-bypassing trend, and large-scale arm posture—while reducing the effective early-stage search space.

During early post-training, only coarse steering is used. At 50k update steps, the fine residual branch is activated and the original high-dimensional per-time-step latent is added as a residual. This recovers fine-grained expressiveness for local obstacle avoidance, end-effector correction, and manipulator joint-pose refinement. The method is therefore not fixed latent downsampling; it explicitly decouples stable global search from later high-dimensional detail refinement.

Why the Two Stabilization Mechanisms Matter

The two mechanisms are complementary: QA warm-up reduces supervision noise for the latent critic, while coarse-to-fine steering reduces the difficulty of searching directly in a full-horizon latent space.
Qualitative comparison

Whole-body Trajectory Generation

The evaluation scenes contain narrow passages, furniture obstacles, and target regions that require coordinated base and arm motion. The main views show the global base path and manipulator motion trend, while the zoomed views reveal the end-effector clearance around obstacles.

Methods without sufficient reward-guided post-training can generate roughly feasible base paths, but their end effectors move closer to obstacles and exhibit less stable local pose changes near the target. RLMM-Flow produces smoother whole-body trajectories, more compact base paths, safer local clearance, and fewer unnecessary joint movements. The visualization is consistent with the quantitative improvements in collision, joint violation, smoothness, and arm-path length.
